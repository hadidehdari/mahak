# 🌟 پروژه مهاک - Mahak

این پروژه یک اپلیکیشن تحت وب بر پایه فریم‌ورک Laravel است که با هدف تحلیل مسیر شغلی، استعدادیابی و ارائه خدمات مشاوره حرفه‌ای طراحی شده است. مهاک می‌تواند به عنوان زیرساختی برای سامانه‌های توسعه فردی، پورتال‌های آموزشی یا سیستم‌های منابع انسانی مورد استفاده قرار گیرد.

## ✨ امکانات کلیدی

- سیستم احراز هویت کاربران (ورود و ثبت‌نام)
- پنل مدیریت برای کنترل کاربران و محتوای سامانه
- ماژول‌های مسیر شغلی و ارزیابی استعداد
- ساختار ماژولار و توسعه‌پذیر با معماری MVC لاراول
- مسیرهای RESTful
- قالب‌های Blade برای رابط کاربری

## ⚙️ تکنولوژی‌های استفاده شده

- PHP نسخه ۸ به بالا  
- Laravel نسخه ۱۰ به بالا  
- پایگاه داده MySQL  
- موتور قالب Blade  
- Bootstrap یا Tailwind (بسته به تنظیمات پروژه)  
- Git و GitHub  

## 📥 نحوه نصب و اجرا

۱. ابتدا مخزن را کلون کنید:
```bash
git clone https://github.com/hadidehdari/mahak.git
cd mahak
````

۲. پکیج‌ها را نصب کنید:

```bash
composer install
npm install && npm run dev  # اگر از بخش فرانت‌اند استفاده می‌شود
```

۳. فایل `.env` را تنظیم و کلید اپلیکیشن را بسازید:

```bash
cp .env.example .env
php artisan key:generate
```

۴. مشخصات دیتابیس را در فایل `.env` وارد کرده و سپس:

```bash
php artisan migrate
```

۵. اجرای سرور توسعه:

```bash
php artisan serve
```

## 🧪 تست‌گیری

برای اجرای تست‌ها از دستور زیر استفاده کنید:

```bash
php artisan test
```

## 🗂 ساختار مهم پروژه

* `app/Http/Controllers` – کنترلرها
* `routes/web.php` – مسیرهای اصلی وب
* `resources/views` – صفحات رابط کاربری
* `database/migrations` – مهاجرت‌های دیتابیس (ساختار جداول)
